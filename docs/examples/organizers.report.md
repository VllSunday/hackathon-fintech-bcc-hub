## Как агент нарезал требования

Спецификация описывает функцию мобильного банка для уведомления клиента о достижении месячного порога расходов по карте. Содержит требования к UI, расчету расходов и дочернюю спецификацию REST API для управления настройками порога.

#### D-015. Противоречие в коде ответа при ошибке валидации

#### D-024. Не указан текст push-уведомления

Критерий: полнота (ISO/IEC/IEEE 29148:2018, п. 5.2.5; IEEE Std 830-1998, п. 4.3.3) · Серьёзность: незначительный · Требования: R-006

В требовании сказано, что клиент получает уведомление, но не задан его текст. Разработчикам неизвестно, какие именно слова и переменные (например, сумму или маску карты) выводить в сообщении, чтобы клиент понял суть уведомления.

> «Ф-3. Когда расходы переходят от суммы ниже порога к сумме, равной порогу или выше, клиент получает push.» — строка 39

**Как исправить.** В разделе «Функциональные требования» указать точный шаблон текста push-уведомления с переменными, например: «Превышен лимит расходов. Месячная сумма достигла {amount} ₸».
