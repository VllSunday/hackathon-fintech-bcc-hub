# Промпты

Каждый промпт — отдельный файл `*.md` с шапкой `id` и `version`. Подстановки пишутся как `{{name}}`, чтобы фигурные скобки в примерах JSON не ломались. Хэш всех файлов попадает в паспорт прогона: любая правка промпта видна в отчёте.

## Язык: инструкции на английском, всё, что пишет модель, — на русском

| Что | Язык | Почему |
|---|---|---|
| Инструкции, правила, определения критериев | английский | Модели надёжнее всего следуют инструкциям и схемам на английском; англоязычные определения ближе к тексту ISO 29148 и IEEE 830 |
| Текст проверяемого документа и цитаты | как в документе | Цитата проверяется кодом посимвольно; перевод или пересказ её ломает |
| Свободные поля ответа: резюме, пояснения, вопросы | русский | Отчёт на русском по условию задачи |
| Ключи JSON, коды критериев, enum | английский | Их читает код; русские названия подставляет отчёт из `criteria.py` |
| Few-shot примеры | русский текст, английская разметка | Пример показывает модели, на каком языке писать поля |

Риски такого смешения и как их закрываем:

1. **Модель отвечает по-английски в свободных полях.** Правило в `system_base.md` и проверка в коде: поле без кириллицы уходит на повтор.
2. **Модель «улучшает» цитату** (меняет кавычки, тире, исправляет опечатку). Запрет в промпте и проверка цитаты в гейте s7.
3. **Разнобой терминов в отчёте.** Модель называет критерии только кодами, русские названия берутся из одного места — `criteria.py`.

Решение проверяется на eval-стенде: промпты стадии можно продублировать на русском и сравнить оба варианта на корпусе. Пока сравнения нет, это решение по умолчанию, а не доказанный факт.

## Файлы

| Файл | Где используется |
|---|---|
| `system_base.md` | Общая часть системного промпта всех ролей: документ как данные, язык, доказательства, суждение |
| `s2_profile.md` | s2: профиль документа — части, нумерация, какие виды требований есть |
| `s2_segment.md` | s2: нарезка на требования и учёт каждого блока; пример из другой предметной области |

Инструкции роли собираются как `system_base` + файл роли (`prompt_store.compose`). Документ в промпт не вставляется: он идёт отдельным сообщением пользователя, внутри тегов `<document>`.
